# Mystery Rooms

Digitale Escape Rooms für den Browser – kostenlos, ohne Anmeldung, direkt spielbar.

- **Startseite:** `index.html` (Katalog mit Filtern, Detailansicht, „So funktioniert’s“, FAQ)
- **Neuen Escape Room eintragen:** einen Eintrag in `portal/games.js` ergänzen
